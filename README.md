Tabnesia (n.) — the sudden forgetting of why you opened a browser tab the moment it loads. A one-line program that writes one newly coined English word and its definition to /output/entry.txt for make.fun's "Invent a Word We Need" bounty.

## Run it

```sh
node cli/makefun.mjs submit --competition u-deranalabs-invent-a-word-we-need-17a020e0 --repo-url https://github.com/GBNK619/invent-a-word-tabnesia --commit <sha> --title "Invent a Word We Need" --bundle transcripts.tar.gz --keypair ~/workspace/makefun/makefun-keypair.json
```
